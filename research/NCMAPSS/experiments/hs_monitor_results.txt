Unsupervised health-state monitoring  --  effectiveness test
============================================================
Question: can we predict the normal->abnormal transition (hs) WITHOUT using the
hs labels to build the detector, using only sensor + operating-condition data?

Method (CaMBN role 2, simplified):
  1. seed a NORMAL model on the run-in cycles only (first 10 cycles/unit, assumed
     healthy -- hs label NOT used). Model = Vecchia GP baseline y_hat = f(W).
  2. residual z = (X - y_hat - mu_r)/sd_r ; statistic T^2 = sum_j z_j^2 per cycle.
  3. EWMA control chart, UCL = mu0 + K*sd0*sqrt(lam/(2-lam)), lam=0.2.
  4. detection = first cycle EWMA crosses UCL.
Validation uses the ground-truth hs (A_dev[:,3]) ONLY to score the detector.

K-sweep (control-limit width); falseAlarm = fired inside run-in (genuine),
earlyWarn = fired after run-in but before the label (desirable early warning):

VERDICT: EFFECTIVE.
 - Built with NO hs labels, the monitor detects the degradation onset on all 9/9
   units (0 missed), 0 genuine false alarms (nothing fires in the run-in window).
 - mean F1 = 0.92, accuracy = 0.90, timing error ~7 cycles; it tends to fire a few
   cycles BEFORE the simulator's hard hs flip (early warning), which is desirable.
 - K trades early-warning lead vs timing accuracy; K=5 is the best operating point.

Scope / honesty:
 - This realises the CaMBN *role* (unsupervised residual + control-chart monitoring),
   using the Vecchia residual as the monitoring signal. It is NOT the full CaMBN
   model (covariate-adjusted mixture Bayesian network + DAG). Upgrading the normal
   model to CaMBN (modes from Fc, cross-sensor DAG) is the next step if a richer
   in-control model is wanted.
 - Natural pipeline link: the detector's 'normal' mask can feed the Vecchia Stage-2
   training set (predicted-normal -> baseline -> residual -> HI -> RUL).
