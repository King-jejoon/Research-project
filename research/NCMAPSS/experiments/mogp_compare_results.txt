VERDICT
-------
The colleague's MOGP-Vecchia code is correct and competitive.  The first run that
looked worse (RMSE 2.0) was an UNDER-TRAINING artefact on my side: the 14-task
coregionalized model needs more optimisation than a single-output GP.  With
adequate settings (m>=80, ~400 steps) it matches ExactGP at 180 points and beats
it (0.816 vs 0.945) -- while, unlike ExactGP, it can also scale to thousands of
normal points via Vecchia for further gains.

Caveats
-------
* Only code change needed to run here: device 'cuda' -> 'cpu' (or 'mps').
* Hyperparameters matter: small m / few steps degrade the multitask fit badly.
* The 2,700-pt run shown earlier (RMSE 1.42) was ALSO under-trained (m=20,120);
  a proper m>=80 / ~400-step run is needed to quantify the large-data gain
  (long: ~30-60 min on CPU).
