# N-CMAPSS two-stage self-supervised RUL chain

Code, results and paper generators for the DS03-012 chain and the v6 transfer study.
Read `RESEARCH_LOG.md` first (current state, ledger, rules, chronology).

## Layout
- `experiments/` — every experiment script (`exp_*.py`), result ledgers (`*_results.txt`), small result arrays (`*.npz` < 5 MB), orchestrators (`run_*.sh`). Large artefacts are NOT in git: `cache*.npz` (rebuild), `*.pt` GP models (refit or rsync), per-point stats/residual `*.npz`.
- `deps/DEMO/` — colleague GP modules (Vecchia MOGP) the chain imports.
- `paper/` — document generators (`make_final_report.js`, `case_study/`), figures, final docx/pdf.
- `exp_paths.py` — machine-independent paths: `NCMAPSS_DATA` (h5 dir), `NCMAPSS_DEMO`, `NCMAPSS_PAPER`.

## Setup on a new machine
```bash
git clone https://github.com/King-jejoon/Research-project.git
cd Research-project/research/NCMAPSS
conda env create -f environment.yml          # env name: pt_prac
export NCMAPSS_DATA=/path/to/N-CMAPSS/h5      # add to ~/.zshrc
cd experiments
python build_cache.py                         # DS03 -> cache.npz (~2 min)
DS=ds08a python build_cache_dsx.py            # any other subset -> cache_<ds>.npz
cd ../paper && npm install                    # docx generator deps
```
GP models (`*.pt`, ~9 MB each) are regenerated by the scripts when missing (10–20 min per fit) or copied with rsync from the workstation.

## Running
- Current DS03 chain: `exp_v5c_dev.py` (dev) → `exp_v5c_test.py` (pre-registered test).
- Transfer chain (any subset): `run_dsx_v3.sh`-style orchestration — c3 → detsel → hi1 → stage2 → test, seed-parallel (`SEEDS_ONLY=0 STATS_ONLY=1`), `NJOBS` workers for inference.
- Documents: `node paper/make_final_report.js en|ko`; `python paper/case_study/make_cs_data.py && node paper/case_study/make_case_study.js`; PDF via `soffice --headless --convert-to pdf`.

Every test-split contact is an "opening": pre-register in the script header, count it in the ledger, report every number regardless of direction.
